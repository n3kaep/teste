# The Veil (Forge)

Forge 1.20.1 (47.2.0+) · Java 17

Compilar:   gradle build        (Gradle 8.1.1 recomendado, JDK 17)
Resultado:  build/libs/veil-1.0.0.jar

Alternativa: baixe o Forge MDK 1.20.1, apague a pasta src dele e copie a pasta src deste projeto no lugar.
Coloque o .jar na pasta mods (cliente e, em multiplayer, servidor).
